# Smart Timetable Generator

A Python and Streamlit application that generates class timetables based on subjects, weekly hours, teacher assignments, and teacher availability.

## Features

- Login page
- Multiple class selection
- Subject and weekly-hour configuration
- Teacher assignment and availability settings
- Automatic timetable generation
- Subject and teacher timetable views
- PDF timetable downloads

## Technologies Used

- Python
- Streamlit
- Pandas
- ReportLab

## Installation

1. Clone this repository.
2. Install the dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`
